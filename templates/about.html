About WebFind

WebFind is a self-hosted, native search engine designed for AI agents and privacy-conscious users. Unlike cloud search APIs, WebFind runs entirely on your infrastructure: it crawls the web, builds a local knowledge graph in SurrealDB, indexes content with BM25 + vector search, and ranks pages using freshness, quality, and graph signals.

The GUI you are using is a Google-style search experience powered by HTMX and Tailwind CSS v4. There is no AI in the search box itself; every query researches the live web behind the scenes and stores the results for future recall.

WebFind is open source. You host it, you control it, you own the data.
